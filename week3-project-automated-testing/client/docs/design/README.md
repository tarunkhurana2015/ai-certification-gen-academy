# After Hours visual reference

The developer selected **A — After Hours** on November 1, 2026 after comparing the Movies Home and movie-details mockups. [after-hours-reference.png](after-hours-reference.png) preserves that selected direction. The binding production rules are in [Stage 4](../../specs/04_design_system_and_responsive.md).

This image is a screenshot of the local browser prototype, not a Flutter screenshot. Movie metadata and navigation were illustrative; they do not assert current TMDB values. The small device frames and presentation-scale text are not production dimensions. The surrounding design-comparison page is not part of Movies.

Artwork was retrieved from the TMDB public image CDN for the authorized local design exploration and visually inspected. This reference does not grant ownership or a broader artwork license. Production attribution follows the approved product scope and TMDB requirements.
