# Architecture diagrams

These PNG previews and scalable SVGs are rendered from the Mermaid blocks in [ARCHITECTURE.md](../../ARCHITECTURE.md), under each “Editable Mermaid source” disclosure. Click a preview to open its SVG. The PNGs use 2× rendering so the warm charcoal palette and ELK line routing display consistently in Markdown viewers.

The original box wording, node shapes, and directed connections are retained. Invisible Mermaid links guide placement only; they add no visible arrows or data flow.

Existing Font Awesome icons in the system design SVG are embedded as vector paths, with attribution and license in [fontawesome-LICENSE.txt](fontawesome-LICENSE.txt).
